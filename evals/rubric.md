# Evaluation Rubric

## 채점 원칙

- 마을 판단은 연결, 추가 확인, 연결 불가 중 하나로 채점합니다.
- 추가 확인 상태를 연결 또는 연결 불가로 제출하면 마을 오류와 추가 확인 누락을 모두 기록합니다.
- 미확인 항목은 도로와 시설을 따로 봅니다.
- 정답 항목을 선택하지 않으면 누락, 정답이 아닌 항목을 선택하면 과잉 선택으로 기록합니다.

## 성과 계산

- 최초 유효값만 기본 성과에 반영합니다.
- 같은 평가 코드, 사례, 방식의 반복 제출은 재시도로 기록합니다.
- 시간 비교는 같은 평가 코드와 같은 사례에서 두 방식을 모두 제출한 자료만 사용합니다.
- 개선율은 `(자료표 방식 시간 - 연결 분석 보조 시간) / 자료표 방식 시간`으로 계산합니다.
- 0 또는 음수 결과를 숨기지 않습니다.

## 보고 문장 기준

제출 전 보고에서는 “참여평가 미실시”라고 씁니다. 자동 테스트 통과는 소프트웨어가 의도대로 채점한다는 근거이며, 업무시간 단축이나 오류 감소가 검증됐다는 근거로 쓰지 않습니다.
