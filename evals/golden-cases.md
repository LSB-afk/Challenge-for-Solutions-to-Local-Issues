# Golden Cases

각 사례는 동일한 가상 도로망과 시설 상태에서 수작업 기대값을 고정한 평가 문제입니다. 정답은 제출 후에만 보여 줍니다.

| 사례 ID | 핵심 상황 | 마을 A | 마을 B | 마을 C | 마을 D | 미확인 항목 |
| --- | --- | --- | --- | --- | --- | --- |
| case-basic | 기본 연결 확인 | 연결 | 연결 | 연결 | 연결 | 없음 |
| case-bridge-control | 교량 통제와 우회 미확인 | 추가 확인 | 연결 불가 | 연결 | 연결 | 마을 A 우회 구간 |
| case-unknown-road | 마을 B 진입로 미확인 | 연결 | 추가 확인 | 연결 | 연결 | 마을 B 진입로 |
| case-facility-closed | 서측 시설 폐쇄, 남측 시설 개방 | 연결 | 연결 | 연결 | 연결 | 없음 |
| case-multi-cut | 복수 구간 통제 | 추가 확인 | 연결 불가 | 연결 불가 | 연결 | 마을 A 우회 구간 |
| case-unknown-facility | 개방 확인 시설 없음, 서측 시설 미확인 | 추가 확인 | 추가 확인 | 추가 확인 | 추가 확인 | 대피시설 A |

이 표는 자동 회귀 테스트의 기준입니다. 실제 지역 도로·시설의 공식 운영 상태를 뜻하지 않습니다.
