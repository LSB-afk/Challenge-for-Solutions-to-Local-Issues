# 침수 3D 화면: Bangkok 레퍼런스 적용

확인일: 2026-10-03. 범위: `/flood` 화면. 이전에 요청한 흰 배경을 유지한다.

## 직접 확인한 화면

- [3D 지도](https://situational-bangkok-flood.web.app/3d/): 첫 안내 패널을 닫고 전체 지도, 검색, 상단 상태 표시줄, 원형 나침반·조작 버튼을 확인했다. 설정은 그래픽 품질 선택 패널이다.
- [모바일 지도](https://situational-bangkok-flood.web.app/m/): 시작 안내·상황 모달과 2D/3D 진입 구조를 확인했다.
- 로컬 비교 이미지: `artifacts/reference-hud/reference-map-closed.png`, `reference-settings.png`. 화면 크기 1440×1000. 사용자 첨부 이미지도 수심 pill과 시설 표식의 기준으로 사용했다.

## 시각 규칙

- 배경 `#ffffff`, 본문 `#203a47`, 보조 `#657985`, 수심 `#2878c7`, 선택/연결 `#087f80`, 제외 `#c34d3b`.
- 시스템 한글 서체, 수심·좌표·시각은 고정폭 숫자. 화면 제목은 작게 유지하고 지리 정보를 주인공으로 둔다.
- 상단 두 행 58px + 37px, 하단 상태 24px. 지도는 나머지 뷰포트를 채운다.
- 모바일은 2행 검색 헤더와 지도 위 패널을 사용한다. 보고서처럼 아래로 길어지는 기존 구성을 없앴다.
- 다크 화면의 구조를 흰색으로 번역했다. 방콕의 도시 밀도·시설 수를 운산면에 복제하지 않는다.

```text
┌ 브랜드 / 지역 검색 / 2D·3D / 중심·잠금·설정 / 시각 ┐
├ 자료 종류 / 겹침·제외·교량 / 지도 중심 좌표 ────────┤
│ 메뉴 · 지역명                    출처    나침반   │
│                                      레이어     │
│     건물 + 수심 범위 + 도로 + 위치별 수심/시설    │
│                                       선택 정보 │
│                                         조작부  │
│ 범례             수심 조건 / 연결 분석           │
└ 자료 범위·출처 / 현재 통행 상태 미확인 ───────────┘
```

## 데이터 해석 유지

- 공식 자료는 직접 조회한 지방하천 100년 빈도 시나리오의 수심 **등급**이다. 정확한 수심이나 실시간 예보로 바꾸지 않는다.
- 예시 수심과 사용자 파일에는 각각 `예시`, `사용자`를 표기한다. 수직 배율은 표시만 바꾸며 도로 제외 계산에 들어가지 않는다.
- 건물 도형은 기존 운산면 공개 자료 전체 ID 검증을 유지한다. 제공처 4,970개 도형을 표시하며 현실의 모든 건물에 대한 완전성을 주장하지 않는다.
- 시설은 주소를 확인한 위치다. 아이콘은 시설 종류를 나타내며 대피소 지정·현재 개방을 뜻하지 않는다.
- 도로는 수심과 겹치는 객체에 가정 조건을 적용한다. 통제 현황·안전 경로 확정으로 표현하지 않는다.
- 레퍼런스의 LIVE 기상, CCTV, SOS, AI 제보 및 항공기는 해당 자료가 연결되어 있지 않아 넣지 않았다.

## 확인할 동작

기본 지도 → 메뉴 → 공식/예시/사용자 자료 → 수심·도로 클릭 → 시설 검색 → 연결 비교. 메뉴·설정·상세는 Escape로 닫고 조작 버튼으로 초점을 돌린다. 지도 엔진 실패 때는 SVG 도식과 분석을 유지한다.
