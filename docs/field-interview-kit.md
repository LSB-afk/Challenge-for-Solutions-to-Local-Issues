# 현장 인터뷰·비교평가 키트

작성일: 2026-10-03  
목적: 제출 전 현장 가설을 검증하고, 공모전 발표에서 “실증 가능한 제안”으로 보이게 할 자료를 준비한다.

이 문서는 연락이나 인터뷰를 수행한 기록이 아니다. 아직 외부 연락 승인이 없으므로 질문지와 평가 절차만 준비했다.

## 확인할 역할과 부서

| 대상 | 공개 근거 | 확인할 이유 |
|---|---|---|
| 운산면 행정복지센터 | 운산면 직원 안내에는 토목공사 및 보수, 환경·민방위 등 업무가 공개돼 있다. | 면 단위에서 실제로 호우 때 어떤 신고·도로·시설 정보를 확인하는지 파악 |
| 서산시 안전총괄과 자연재난팀 | 자연재난팀은 자연재난 상황관리, 피해조사, 침수흔적도 작성, 재난안전대책본부 운영 등을 담당한다. | 시 단위 공식 대응 체계와 침수·통제 자료의 보유 여부 확인 |
| 건설·하천·도로 관련 부서 | 서산시의회 회의록에는 원평천 재해복구와 교량·도로 사업 보고가 있다. | 원평소하천 주변 교량·도로의 공사·통제·우회 상태 확인 |
| 대피시설 관리 부서 또는 시설 관리자 | 국민재난안전포털 등 시설 목록은 좌표와 지정 여부만으로 운영상태를 보장하지 않는다. | 풍수해 시 실제 개방 절차, 수용 여건, 진입로 상태 확인 |

개인 이름이나 개인 연락처를 문서에 수집하지 않는다. 역할과 부서 단위로 확인한다.

## 30분 인터뷰 진행표

| 시간 | 주제 | 목표 |
|---|---|---|
| 0-3분 | 취지 설명 | 공모전 제안 검증이며, 기존 업무를 평가하려는 자리가 아님을 설명 |
| 3-8분 | 호우 비상근무 흐름 | 신고 접수, 상황 확인, 보고, 주민 연락, 근무 인계 순서 파악 |
| 8-15분 | 자료와 시스템 | 어떤 화면·문서·전화·단체방·공문으로 도로·시설 상태를 확인하는지 확인 |
| 15-22분 | 어려운 장면 | 위치가 애매한 신고, 교량 통제, 시설 미개방, 교대 인계에서 실제로 막히는 지점 확인 |
| 22-27분 | 프로토타입 반응 | 미확인 도로 영향 비교, 출처·확인시각, 인계 표가 도움이 되는지 확인 |
| 27-30분 | 반증 질문 | 이 제안이 필요 없거나 위험해지는 조건, 기존 시스템이 이미 해결하는 기능 확인 |

## 핵심 질문

| 구분 | 질문 | 왜 묻는가 |
|---|---|---|
| 업무 흐름 | 호우특보 이후 운산면에서 가장 먼저 확인하는 정보는 무엇인가? | 실제 시작점을 맞추기 위해 |
| 업무 흐름 | 도로 통제나 교량 이상 신고가 들어오면 누가, 어디에, 어떤 형식으로 기록하는가? | 인계 기능의 실제 위치를 확인하기 위해 |
| 자료 | 원평리·고풍리 주변 도로·교량 상태를 확인할 때 쓰는 공식 자료나 내부 화면이 있는가? | 중복 개발 여부 확인 |
| 자료 | 침수흔적도, 피해조사, 통제 시각 기록을 공간자료로 받을 수 있는가? | 평가 시나리오의 정답 자료 확보 가능성 확인 |
| 시설 | 풍수해 때 실제로 열 수 있는 대피시설은 어디이며, 개방 여부는 누가 확인하는가? | 시설 좌표와 운영상태를 분리하기 위해 |
| 판단 | 한 교량이 통제됐을 때 어느 마을이 영향을 받는지 현재는 어떻게 판단하는가? | 도로 그래프 기능의 필요성 확인 |
| 인계 | 교대자가 놓치기 쉬운 정보는 무엇인가? | 인계 표의 필수 항목을 정하기 위해 |
| 신고 구조화 | 신고 문장에서 지명 후보와 위험유형을 자동 후보로 뽑는 기능이 도움이 되는가? | 현재 규칙 기반 기능의 현장 적합성과 향후 AI 적용 범위를 구분하기 위해 |

## 반증 질문

이 질문은 제안을 약하게 만들 수 있는 사실을 먼저 찾기 위한 것이다. 답이 “예”이면 방향을 조정한다.

| 질문 | 조정 방향 |
|---|---|
| 기존 내부 시스템이 이미 마을-대피시설 접근성과 통제 반영을 계산하는가? | 독립 서비스가 아니라 기존 시스템의 인계·현장확인 보완 모듈로 제안 |
| 원평소하천 주변의 도로·교량 자료가 분석에 충분하지 않은가? | 시범구역을 자료 검수 가능한 더 작은 구간으로 축소 |
| 비상근무 중 새 화면을 볼 여유가 거의 없는가? | 전체 지도보다 인계 표와 확인 우선순위 문자·출력물 중심으로 축소 |
| 3D 화면이 판단을 느리게 만드는가? | 2D와 목록을 기본으로 하고 3D는 설명·교육·사후검토 화면으로 제한 |
| AI 추출 오류가 현장에 부담을 주는가? | AI를 자동 입력이 아니라 후보 제시·보류 중심으로 제한 |

## 비교평가 절차

같은 시나리오를 두 방식으로 처리한다. 사람 평가가 어렵다면 먼저 팀 내부에서 절차를 검증하고, 현장 인터뷰 후 실제 담당자 평가로 전환한다.

| 단계 | 기존 방식 | 프로토타입 방식 | 측정값 |
|---|---|---|---|
| 1. 시나리오 제시 | 신고 3건, 도로 통제 2건, 시설 상태 2건을 문서로 제공 | 같은 조건을 프로토타입에 입력 | 시작 시각 |
| 2. 영향 마을 찾기 | 지도·문서·목록을 보고 수동 판단 | 도로 연결 분석과 미확인 영향 비교 사용 | 완료 시간, 누락 마을 수, 과잉 표시 수 |
| 3. 확인 우선순위 작성 | 담당자가 이유를 직접 정리 | 확인할 도로의 마을 영향 수와 근거 확인 | 설명 가능 여부, 우선순위 일치 |
| 4. 인계 작성 | 자유 양식 또는 기존 양식 | 출처·확인시각·미확인·다음 조치 표 출력 | 필수 항목 누락 수 |
| 5. 사후 질문 | 어려웠던 점 기록 | 부담·오류·필요 없는 화면 기록 | 개선 의견 |

## 판정 기준

| 항목 | 통과 기준 |
|---|---|
| 통제 구간 처리 | 확인된 통제 구간이 후보 경로에 남지 않는다. |
| 미확인 처리 | 미확인 도로가 있으면 안전한 경로로 확정하지 않고 확인 필요로 남긴다. |
| 우선순위 설명 | 상위 확인 대상마다 영향을 받는 마을·시설과 출처를 설명할 수 있다. |
| 인계 완결성 | 다음 근무자가 미확인·미회신·조치 필요 항목을 재구성할 수 있다. |
| 과장 방지 | 측정 전에는 시간 절감률, 피해 예방액, AI 정확도 수치를 쓰지 않는다. 현재 규칙 기반 구조화 정확도만 별도로 측정한다. |
