# 업무 비교 평가 계획

이 문서는 운산면 고립 대응 프로토타입의 효과를 과장하지 않고 검증하기 위한 실행 계획입니다. 현재 상태는 연구 실증이 아니라, 같은 가상 상황을 두 방식으로 풀어 보는 내부 평가 워크벤치입니다.

## 비교 대상

- 자료표 방식: 실제 현행업무 대용입니다. 같은 도로·시설 상태를 표로만 제공합니다.
- 연결 분석 보조: 같은 입력에 대해 마을별 연결 상태, 추가 확인 필요 여부, 근거 경로를 함께 제공합니다.

두 방식 모두 동일한 가상 도로·시설 상태를 사용합니다. 연결 분석 보조가 더 많은 원자료를 받은 것이 아니라, 같은 자료를 연결 관점으로 정리한 것입니다.

## 측정 항목

- 시작부터 제출까지의 실제 경과시간
- 마을별 연결 판단 오류
- 추가 확인이 필요한 마을을 놓친 횟수
- 미확인 도로·시설 누락
- 미확인 도로·시설 과잉 선택

시간 개선율은 같은 평가 코드와 같은 사례에서 두 방식을 모두 완료한 짝지어진 자료만 계산합니다. 같은 코드·사례·방식 조합을 여러 번 제출하면 최초 유효값만 성과 계산에 반영하고, 이후 값은 재시도로 표시합니다.

## 순서 효과 관리

참여자는 AB 또는 BA 순서를 배정받습니다.

- AB: 자료표 방식 후 연결 분석 보조
- BA: 연결 분석 보조 후 자료표 방식

작은 표본에서 30% 개선 같은 목표값을 미리 정하지 않습니다. 결과는 중앙 시간 차이, 중앙 변화율, 오류 차이를 함께 보고합니다. 음수 변화율은 연결 분석 보조가 더 오래 걸린 경우입니다.

## 현재 한계

- 실제 공무원 업무 실증이나 현장 인터뷰 결과가 아닙니다.
- 사례는 독립 수작업 기대값을 둔 가상 과제입니다.
- 자동 회귀 테스트는 평가 엔진이 깨지지 않았는지 확인하는 자료이며, 사람의 업무효과 결과가 아닙니다.
- 실제 제출 전에는 최소 5명 이상에게 파일럿을 돌려 문항 이해 오류를 먼저 확인해야 합니다.
