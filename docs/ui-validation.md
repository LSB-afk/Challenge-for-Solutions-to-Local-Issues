# UI 개선 검증 기록

2026-10-02

- Node 구문 검사 통과. 의존성 추가 없음.
- 자동 테스트 41개 통과: 연결 계산, 개별 근거 최신성, 원본 건물 ID 전량 검증, 지도 실패 대체 도식, 신고·출처 필터, 검색, 정적 서버.
- 데스크톱 1280×800, 모바일 390×844에서 직접 조작.
- 검색 결과의 방향키 이동·Enter 선택, 시연 도로 상세 이동 확인.
- 도로 통제 상태를 개방으로 바꿀 때 상단 통제 수가 2→1, 해당 목록 수가 2→1로 갱신됨.
- 같은 상태 재확인 시 도로 확인 시각이 훈련 06:30으로 갱신됨.
- 미확인 신고 저장 시 대기 수 0→1, 관련 마을 배지 1 표시. 도로 상태는 변경되지 않음.
- 출처 필터에서 상황 표식과 신고 표시가 구분됨. 신고 보기에서 마을 기준점은 중립색으로 표시.
- 신고 보기에서 도로 검색 결과를 선택하면 상황 근거로 전환되고 도로 상세가 열림.
- 모바일 상세 확장·접기, 목록/지도 전환 확인. 제목이 고정되어 상세 접기 조작 가능.
- 지도 넓게 보기, 전체 보기 반복, 2D/3D 전환 확인. 누적 카메라 여백으로 중심이 밀리던 문제 수정.
- 건물 자료 ‘운산면 건물 4,970개 · 표시 중’ 확인. 실제 높이 미제공 안내 유지.
- 페이지 가로 넘침 없음(데스크톱), 브라우저 콘솔 오류 없음.
- 로컬 검증용 신고·변경 기록은 시연 초기화로 정리.

현장 통행 안전·실제 수심·건물 전수조사·외부 서비스 장기 가용성은 검증 범위가 아니다.
