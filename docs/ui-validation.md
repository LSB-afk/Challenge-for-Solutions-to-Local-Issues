# UI 개선 검증 기록

2026-10-02

- Node 구문 검사 통과. 의존성 추가 없음.
- 자동 테스트 41개 통과: 연결 계산, 개별 근거 최신성, 원본 건물 ID 전량 검증, 지도 실패 대체 도식, 신고·출처 필터, 검색, 정적 서버.
- 데스크톱 1280×800, 모바일 390×844에서 직접 조작.
- 검색 결과의 방향키 이동·Enter 선택, 시연 도로 상세 이동 확인.
- 도로 통제 상태를 개방으로 바꿀 때 상단 통제 수가 2→1, 해당 목록 수가 2→1로 갱신됨.
- 같은 상태 재확인 시 도로 확인 시각이 훈련 06:30으로 갱신됨.
- 미확인 신고 저장 시 대기 수 0→1, 관련 마을 배지 1 표시. 도로 상태는 변경되지 않음.
- 출처 필터에서 상황 표식과 신고 표시가 구분됨. 신고 보기에서 마을 기준점은 중립색으로 표시.
- 신고 보기에서 도로 검색 결과를 선택하면 상황 근거로 전환되고 도로 상세가 열림.
- 모바일 상세 확장·접기, 목록/지도 전환 확인. 제목이 고정되어 상세 접기 조작 가능.
- 지도 넓게 보기, 전체 보기 반복, 2D/3D 전환 확인. 누적 카메라 여백으로 중심이 밀리던 문제 수정.
- 건물 자료 ‘운산면 건물 4,970개 · 표시 중’ 확인. 실제 높이 미제공 안내 유지.
- 페이지 가로 넘침 없음(데스크톱), 브라우저 콘솔 오류 없음.
- 로컬 검증용 신고·변경 기록은 시연 초기화로 정리.

현장 통행 안전·실제 수심·건물 전수조사·외부 서비스 장기 가용성은 검증 범위가 아니다.

## 2026-10-03: 침수 3D 전체 지도 UI

- Bangkok 3D 사이트를 실제 열어 메뉴를 닫은 지도와 설정 패널을 확인했다. 사용자 첨부 이미지의 수심 pill, 시설 원형 표식, 상단 2단 HUD를 흰 배경으로 적용했다.
- 기본 화면에서 고정 왼쪽 열과 큰 소개 문구를 제거했다. 분석 메뉴·설정·선택 정보는 지도 위에서 열고 닫는다.
- 화면 비교 후 시설 표식의 제목 가림, 모바일 범례 충돌, 출처 표시의 버튼 차단을 수정했다.
- Node 테스트 89개 통과. 새 검증: 모든 지도 입력 잠금/해제, 카메라 좌표 전달, 공식 구간 표식 유지·제거, 도식 모드 레이어 전환.
- 브라우저 조작 검사 21개 통과. 검색·키보드 초점·Escape·레이어·시나리오·CSV·업로드 검증·기존 저장 기록 보존을 포함한다.
- 선택한 도로/수심을 재계산할 때 메뉴·설정이 닫히지 않는 회귀 검사를 추가했다.
- 로컬에 보관된 제공처 원본 ZIP으로 320개 공식 구역 로드, 구간 수심 표시, 공식 자료 내보내기 제한을 확인했다. 원본은 저장소·배포물에 포함하지 않았다.
- 건물 서비스 실조회로 공개 건물 도형 4,970개 로드를 확인했다. 1440×1000과 390×844에서 지도·메뉴·설정 화면을 캡처했다.
- 지도 라이브러리 차단 시 SVG 도식과 수심/도로 레이어 선택이 유지됨을 확인했다.
- 브라우저 페이지 런타임 오류 0건. 외부 배경지도 스타일의 기존 경고와 장기 가용성은 이번 변경의 검증 대상에 포함하지 않는다.
- 추가 320/390/900px 검사에서 헤더 넘침, 상태·배율 문구 겹침, 범례·건물 상태 겹침 없음.
- `npm run check`, `npm run build`, `git diff --check` 통과. 신규 의존성 없음.
