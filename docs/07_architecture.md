# 침수 3D 분석 구조 · 2026-10-03

## 목적과 범위
사용자의 즉시 구현 요청에 따라 기존 흰 배경 상황판에서 진입하는 침수 3D 분석 화면을 추가한다. 수심별 범위, 입체 높이, 공개 도로망과 겹치는 구간, 시설 사이 연결 후보를 비교한다. 현재 운영 시연 데이터와 기록은 유지한다.

## 데이터와 신뢰 경계
- 공개 도로: 기존 원평리·고풍리 주변 OSM 313개 형상. 좌표가 같은 꼭짓점만 연결한다. 방향·통행권·도로 폭·시설 출입구가 검증되지 않아 실제 길안내를 제공하지 않는다.
- 시설: 공식 주소 6곳, 좌표 대조 5곳. 풍수해 대피시설 지정과 개방 상태는 미확인이다.
- 공식 수심: 서산시 지방하천 100년 빈도 SHP를 제공처에서 직접 읽는다. N330~N334 구간을 보존하며 대상 bbox와 교차하는 원본 폴리곤을 선택한다. 대상 권역 북동측 일부만 포함한다. 구간 상한을 표현 높이로 쓰며 정확한 수심으로 분석하지 않는다.
- 수심: 출처가 있는 GeoJSON Polygon/MultiPolygon의 depth_m(미터)을 사용한다. 기본 제공값은 합성 예시이며 실측·홍수 예측이 아니다. 사용자 파일은 브라우저 메모리에서만 처리하고 공식 인증으로 표시하지 않는다.
- 건물: 기존 전체 ID 대조 조회 재사용. 원본 윤곽 유지. 선택 가능한 층수×3m 입체화는 표현용 가정이며 실측 높이와 구분한다. 층수가 없으면 윤곽만 표시한다.
- 수심 입체화: 지면 기준 수심의 입체 표현. 수면 표고·수리모형을 계산하지 않는다. 수직 표시 배율은 범례에 계속 표시하며 분석 수심에는 적용하지 않는다.

## 구성과 흐름
flood.html/css/js(UI) → flood-analysis.js(검증·교차·도로 그래프) → flood-map.js(MapLibre/2D 대체도).
공식 조회는 flood-official-worker.js에서 다운로드·압축 해제·도형 해석을 처리하고 진행 상태와 최종 도형만 UI로 전달한다. 조회 취소 시 Worker를 종료한다.
공개 로컬 도로·시설 자료 + 수심 자료 → 도로 객체별 최대 교차 수심 → 선택 기준 이상 제외한 가정 → 시설 간 이전/이후 연결 후보.
침수 영역 밖은 안전으로 분류하지 않는다. 연결이 없으면 수집 범위/입력조건 내 후보 미발견이라고 표시한다. 교량은 상판 표고 미확보를 별도 표시한다. 침수와 겹친 교량을 확인 없이 안전 경로에 포함하지 않는다.

## 외부 서비스
OpenFreeMap: 배경 스타일·타일 요청에 뷰포트 정보만 전송, 장애 시 밝은 바탕과 자체 도형 유지.
Esri Korea MOIS: 기존 운산면 건물 필터/ID 요청, 건물 도형·층수 수신, 원본 링크·이용 조건 표시, 오류 시 재시도 제공. 메모리에서만 사용.
공식 홍수 지도: flood-official.js가 원본 ZIP을 인증정보 없이 공개 조회하고 ZIP·SHP·DBF·EPSG5186 좌표를 메모리에서 해석한다. 공공누리 제4유형 출처/조건을 표시하고 공식 원본·변환 파일을 배포하거나 내보내지 않는다. 자료 사용의 법적 허락을 자동으로 확보하는 설계는 아니며 재사용·제출 범위는 제공기관 확인이 필요하다. 공개 다운로드 API의 지속 제공은 보장되지 않아 조회 실패 시 기존 정상 자료를 유지한다.
외부 AI·신고 발송·위치 권한 요청 없음.

## 상태·오류·검증
분석 선택값과 가져온 파일은 메모리에 유지한다. 기존 localStorage의 운영 상태를 변경하지 않는다. 검증 실패 파일은 기존 정상 자료를 보존하고 오류를 알린다. 파일 크기/좌표/수심/도형 개수 제한을 둔다. 지도 실패 시 2D 도식과 분석 표 제공. 예시/사용자 CSV는 자료 종류·수심 조건·도로망 한계를 포함한다. 공식 모드는 내보내기를 막는다. 조회 취소/자료 교체 시 이전 비동기 응답은 무시한다.
검증: 구멍·다중 도형·교차·경계, 잘못된 수심과 좌표, 경로 단절·우회·스냅 실패·미확인 시설, 원본 불변, PC/모바일·2D/3D·파일 교체·다운로드·지도 실패.

## 수심 구간 처리

- 등급 상한 ≤ 제외 기준이면 기준 미만으로 처리한다(상한 미포함).
- 등급 하한 ≥ 제외 기준이면 해당 도로 객체 전체를 제외한다.
- 기준이 등급 안에 있으면 정확한 초과 여부를 모르므로 `depth-review`로 표시하고 제외 가정에 포함한다.
- 교량은 침수 도형과 겹치면 상판 고도가 확인되지 않아 `bridge-review`로 별도 표시한다.
- 시설 중심점→가까운 도로 꼭짓점 진입 연결에도 동일 수심 조건을 적용한다. 출입구의 실제 위치·통행 가능성은 확인되지 않았다.

## ArcGIS와의 관계

도로망에 제약을 적용해 시설까지의 후보를 비교하는 개념을 구현했다. ArcGIS SDK나 Network Analyst를 사용하지 않는다. 일방통행, 회전제약, 차량 높이·폭, 이동시간, 실시간 교통, 공식 시설 운영자료는 아직 반영하지 않는다. 자체 홍수 예측 모델을 구축했다는 의미도 아니다.
