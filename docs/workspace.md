# GitHub 작업 공간

GitHub에 올릴 루트는 이 `prototype/` 폴더입니다. 상위 폴더에는 공모전 조사자료와 작업 중 산출물이 섞여 있으므로, 저장소에는 `prototype/` 내부 파일만 올립니다.

## 구조

- `dist/`: 실제 서비스되는 정적 파일입니다. 현재는 빌드 도구 없이 사람이 직접 작성한 산출물을 그대로 배포합니다.
- `server.mjs`: Node.js 내장 모듈만 쓰는 로컬 개발 서버입니다.
- `tests/`: Node 기본 테스트 러너로 실행하는 회귀 테스트입니다.
- `docs/`: 공개 가능한 문제 정의와 근거 기록입니다. 업로드된 개인 PDF나 원본 사본은 포함하지 않습니다.
- `.github/`: CI와 이슈·PR 템플릿입니다.
- `.devcontainer/`: Codespaces와 Dev Container용 Node 24 환경입니다.

## 실행 기준

```bash
npm run dev
npm run check
npm test
```

`npm run dev`는 기본으로 `127.0.0.1:4173`에서 `dist/`를 제공합니다. 필요하면 `HOST`와 `PORT` 환경변수로 바꿀 수 있습니다.

## 데이터 반영 방식

현재 도로, 시설, 통제, 영향 범위는 시연 데이터입니다. 향후 공식 자료를 반영할 때는 다음 순서로 처리합니다.

1. 자료 출처, 이용 허가, 갱신일, 담당기관을 `docs/00_source-log.md`에 먼저 기록합니다.
2. 실제 자료와 시연 자료가 섞이지 않도록 `dist/data.js`의 항목별 `source` 또는 표시 문구를 갱신합니다.
3. 도로망과 시설 상태가 바뀌면 `tests/engine.test.js`에 기대 결과를 추가합니다.
4. 공식 대피 판단으로 오해될 문구가 없는지 README와 화면 문구를 함께 확인합니다.

공식 데이터가 아직 없거나 권한이 확인되지 않은 항목은 빈칸을 가상 수치로 채우지 않습니다. “미확인”으로 표시하고, 확인해야 할 질문을 문서에 남깁니다.
