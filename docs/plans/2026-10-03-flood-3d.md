# 침수 3D 구현·검증 계획

1. 공식 침수 자료의 제공 범위·접근 조건을 조사하고 출처 기록.
2. 깊이 GeoJSON 검증, 도형 교차, 공개 도로 그래프의 조건 전후 연결 비교와 독립 테스트 구현.
3. 별도 침수 3D 화면에 시나리오, 깊이 범례, 입체 표현, 시설 선택, 영향 구간·경로, 자료 불러오기/내보내기 구현.
4. 기존 상황판·지역근거에서 진입 연결. 운영 상태 변경 없음 확인.
5. 자동 검사와 PC/모바일 브라우저 검증, 독립 검토 후 GitHub 및 기존 사이트에 반영.

결정: 기존 지도 엔진을 재사용하고 새로운 의존성을 추가하지 않는다. 공개 도로망 분석은 형상 연결 실험으로 명시하며 실제 대피 경로로 확정하지 않는다. 공식 수심을 확보하지 못하면 그 한계를 표시하고 예시값·사용자 자료 기능을 제공한다.
